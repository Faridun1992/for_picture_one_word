# Changelog

Важные изменения проекта по датам.

## 2026-09-27

- Зафиксировано начальное ТЗ игры, границы MVP, UX и Unicode требования для таджикского языка.
- Рекомендован отдельный web-first клиент на Capacitor и Laravel modular monolith backend.
- Спроектированы первичная ER-модель, REST API v1, правила серверной экономики и идемпотентности.
- Добавлен пошаговый план разработки; реализация приложения ещё не начиналась.
- Текущее состояние репозитория: Laravel 13/PHP 8.4, фронтенд Vite; требуется аудит существующих изменений перед кодом.
- Аудит TASK-010 завершён: все четыре миграции применены, фактическая таблица users совпадает с миграцией; Vite пока собирает только web assets. Обнаружено отсутствие intl в PHP контейнере и расхождение дополнительных fillable User-атрибутов со схемой.
- Завершены TASK-012/013: создан отдельный Capacitor 8.5.2 Android/iOS shell, JavaScript/Vite клиент, централизованная конфигурация API URL и пример переменных окружения. `npm run build` и `npx cap sync` прошли; нативные бинарники в этой Linux-среде не собирались. App ID временный.
- `npm audit` нашёл moderate advisory в транзитивной цепочке CLI/build tooling (`@capacitor/cli` → `xcode` → `uuid`); runtime-пакеты не затронуты, анализ исправления запланирован отдельной задачей.
- Завершена TASK-014: Compose MySQL/Redis работают, все существующие миграции применены, Laravel подключается к MySQL и Predis Redis.
- Завершены TASK-015/016: Laravel 13 `install:api` установил Sanctum 4.3.3 и создал token migration/API routing; `User` получил `HasApiTokens`, добавлен `/api/v1/health`. Миграция токенов применена к локальной MySQL.
- Добавлен feature-тест `/api/v1/health`: прошёл 1 тест/2 assertions; среда показывает существующие PHP 8.5 deprecation warnings от `PDO::MYSQL_ATTR_SSL_CA`.
- Завершена TASK-017: PHP local/stage/prod Dockerfile собирают `intl` на ICU, Composer требует `ext-intl`, локальный PHP контейнер пересобран. `composer validate --strict`, проверка `Normalizer` и API feature test прошли.
- Завершена TASK-018: добавлен scoped npm override `xcode → uuid@^11.1.1`; `require('xcode')`, `npm run build`, `npx cap sync` и `npm audit` прошли; npm сообщил `0 vulnerabilities`.
- Завершена TASK-019: ошибки `/api/*` сериализуются в единый envelope с кодами ошибок, статусами и полевыми сообщениями validation; 5xx не раскрывают внутреннюю информацию, web-ошибки не меняют рендеринг. Feature tests прошли: 2 теста/6 assertions.
- Завершена TASK-021: добавлены категории и локализованные названия с FK, уникальными slug и парой категория/locale, индексом `(locale, name)`, моделями, фабриками и повторно запускаемым сидером RU/TJ/EN. MySQL миграция применена.
- Завершена TASK-022: добавлена таблица уровней с FK к категории, индексами каталога, enum/cast `LevelStatus`, фабрикой и идемпотентным сидером черновиков. Сложность 1–5 валидируется приложением при создании/редактировании уровней; FK запрещает удалить занятую категорию. Миграция MySQL применена; все 9 feature tests прошли (19 assertions).
- Завершена TASK-023: добавлена таблица переводов уровня, уникальность `(level_id, locale)`, JSON плитки, языковой список конфигурации и серверный `AnswerNormalizer` (NFC → Unicode case fold → NFC, trim Unicode-пробелов по краям). Feature-наборка прошла: 13 тестов/28 assertions, включая таджикские буквы, русский/английский регистр и канонически эквивалентные строки; MySQL миграция применена. Seeder использует ровно приведённый в ТЗ пример RU/TJ/EN как черновой уровень.
- Завершена TASK-024: добавлена таблица метаданных изображения, FK уровня, nullable dimensions/variants, уникальная позиция на уровень, модель/factory и валидатор строго четырёх позиций `[1, 2, 3, 4]`. MySQL миграция применена; запущено 17 feature/unit тестов, 38 assertions, ошибок нет (PHP 8.5 сообщил deprecation notices из существующей конфигурации PDO). Файлы хранятся вне БД; validator готов для вызова публикацией на TASK-044.
- Принято архитектурное решение ADR-001: гостевая игровая сущность — отдельный `Player`; обязательные поля и web-аутентификация `User` остаются без изменений. `players.user_id` nullable/unique, привязка существующего профиля сохраняет его ID и игровой прогресс.
- Настроено сохранение контекста между AI-сессиями: `AGENTS.md` — канонический общий workflow, `CLAUDE.md` импортирует его для Claude Code, оба файла включены в Git; `TASKS.md` содержит актуальную сводку и следующий шаг. Код приложения не менялся.
- Завершена TASK-020: добавлены `players` с nullable unique FK `user_id` и локалью, Sanctum-модель `Player`, factory/seeder, связь с `User` и middleware `player` для ограничения игровых bearer-маршрутов. Тесты подтвердили default locale, сохранение ID при привязке, уникальность связи, отвязку при удалении аккаунта, доступ токена `Player` и запрет токена `User`; 6 feature tests прошли на SQLite (9 assertions). MySQL миграция не применена: Docker daemon в среде недоступен. Для доступа к связи обнаружено и удалено использование несуществующей `App\\Traits\\UserSettings` в `User` (поиск не нашёл trait в репозитории).
