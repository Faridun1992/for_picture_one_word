# Changelog

Важные изменения проекта по датам.

## 2026-09-27

- Зафиксировано начальное ТЗ игры, границы MVP, UX и Unicode требования для таджикского языка.
- Рекомендован отдельный web-first клиент на Capacitor и Laravel modular monolith backend.
- Спроектированы первичная ER-модель, REST API v1, правила серверной экономики и идемпотентности.
- Добавлен пошаговый план разработки; реализация приложения ещё не начиналась.
- Текущее состояние репозитория: Laravel 13/PHP 8.4, фронтенд Vite; требуется аудит существующих изменений перед кодом.
